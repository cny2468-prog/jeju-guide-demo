# 제주 여행 안내 · 개인정보 없는 체험판

[앱 열기](https://cny2468-prog.github.io/jeju-guide-demo/)

기존 운영 앱과 분리된 별도 앱입니다. 학교·학급·실제 방 및 버스 배정·학생 정보·원본 제출 서버를 포함하지 않습니다. 사진 업로드·수집 기능은 없습니다. 관광지 안내 사진과 개인별 객실 배정이 없는 대표 피난도를 표시합니다.

소감문은 이 브라우저에만 저장되며 서버로 전송되지 않습니다. 이름·학번·연락처를 입력하지 마세요. 장소와 코스별로 모아보고 엑셀을 내려받을 수 있습니다.

## 빌드와 배포

Node.js 24에서 `npm run build`를 실행하면 `pages-dist`에 정적 사이트가 만들어집니다. main 브랜치에 푸시하면 GitHub Actions가 GitHub Pages로 배포합니다. 외부 데이터베이스·스토리지·환경변수·비밀키를 사용하지 않습니다.

지도 타일과 관광지 사진의 출처 및 라이선스는 화면과 public/vendor의 라이선스 파일에 표시되어 있습니다.
